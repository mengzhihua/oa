# OA 亮点

OA 把组织人事、考勤、审批、薪资和协同放在一起，并给其他系统提供统一登录。

1. **审批能带条件，也能多人处理。** 流程有节点、条件分支、转办和撤回，待办记在具体审批人身上。
2. **考勤和工资算在同一套人事数据上。** 排班、打卡、请假走到日结月结；工资计入加班、扣款、社保、公积金和累计预扣个税。
3. **集团系统用授权码加 PKCE 登录。** 不把 OA 的账号密码散落到采购、ERP 或客户系统里。
4. **控制塔发起的审批能带业务单号。** 开放接口按流程编码发起，并把控制塔的业务键记到流程上；同意待办时用这张待办自己的审批人。
5. **登录页上的通用流程不拿来夹业务单。** 那条口不允许带业务编号。要让审批对应一张采购或开票单，走开放接口，而不是通用发起页。
